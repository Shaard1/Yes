# Yes

Don't mind this repo. It's for school. The cube is doing its best, and so am I.

A computer graphics lab using Python, Pygame, and OpenGL. It draws a colorful 3D cube that you can move, rotate, and resize. Very advanced cube activities.

## Run it

Install Python, then run these commands in the project folder:

```sh
python -m pip install pygame PyOpenGL
python 04_Lab1.py
```

## Controls

| Key | What happens |
| --- | --- |
| W / A / S / D | Move the cube |
| Arrow keys | Rotate the cube |
| Z / X | Shrink / grow the cube |
| Close the window | Free the cube |
